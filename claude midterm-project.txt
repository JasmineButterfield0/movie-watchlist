⏺ The push failed because Git needs GitHub credentials. A few ways to fix this:

  Option 1 — GitHub CLI (easiest)
  brew install gh
  gh auth login
  Then retry git push -u origin main.

  Option 2 — Personal Access Token (PAT)
  1. Go to GitHub → Settings → Developer settings → Personal access tokens →
  Generate new token (classic)
  2. Give it repo scope
  3. Then update your remote to include your credentials:
  git remote set-url origin https://JasmineButterfield0:<YOUR_TOKEN>@github.com/
  JasmineButterfield0/movie-watchlist
  git push -u origin main

  Option 3 — SSH
  ssh-keygen -t ed25519 -C "your@email.com"
  # Add the public key to GitHub → Settings → SSH Keys
  git remote set-url origin
  git@github.com:JasmineButterfield0/movie-watchlist.git
  git push -u origin main

  The GitHub CLI (gh auth login) is the quickest for most people — it handles
  everything interactively. Once authenticated, come back and run git push -u 
  origin main again.
